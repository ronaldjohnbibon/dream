# bigasan application
- pautang
- 2 gives
- 1 month to pay
- + points on every order
- + points on on-time payment
- gcash payment through QR code only then send the payment details ( reference / screen shot ).

# User
- can see points.
- can order.
- if previous order fully paid can order and if not can't order.
- free deliver ( daang-hari only ).
- points will be converted as money, and how much points/money you got can be used on order or buy a 1 sack only points if you have more points.

- manage user ( details, points, rice, etc. )
